# Z Agent v4.0.0 — Personal AI Assistant

Owner: Zohaib Mughal
Agent: Z Agent
Language: Urdu + English

## What is functional
- Real Google Gemini API connection configured by the owner at runtime.
- Encrypted API-key storage.
- Text chat with conversation memory.
- Speech recognition + TTS.
- Continuous foreground listening loop.
- Wake-word mode.
- Android app/web/dialer/email/SMS/reminder actions.
- Accessibility and notification-access entry points.
- GitHub Actions debug APK build + artifact upload.

## Important
The APK does not contain an OpenAI/ChatGPT secret key and cannot legitimately include one. If an OpenAI provider is desired, the owner must supply their own API credentials or connect a private backend. Android permissions and each app's official security model remain authoritative.
